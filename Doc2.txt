Design each important page around a clear business objective.

1. Strong primary headline (H1)
2. Clear customer problem or opportunity
3. Specific value proposition
4. Supporting explanation
5. Primary CTA

Hero → Problem → Solution → Services → Benefits → Process → Evidence → FAQs → CTA

### Copywriting principles

Use:

- Benefit-driven headlines
- Problem–Agitate–Solution (PAS)
- Attention–Interest–Desire–Action (AIDA)
- Clear differentiation
- Specific and verifiable claims
- Natural language
- Search-intent alignment
- Clear conversion pathways
- Contextual internal links
- Helpful, original content

Do not use clickbait, exaggerated claims, keyword stuffing, or fabricated credibility signals.

# PHASE 4 — ADVANCED TECHNICAL SEO

Implement a comprehensive technical SEO foundation.

### Essential requirements

- Search-friendly URL structure
- Server-rendered or prerendered important content
- Unique page titles

- Correct H1–H6 hierarchy
- Canonical URLs
- XML sitemap generation

- Proper index/noindex handling
- Descriptive image alt text
- Internal linking strategy
- Breadcrumb navigation
- Open Graph metadata
- Social sharing metadata
- Redirect management
- Custom 404 and error pages
- Correct HTTP status codes
- Pagination handling where necessary
- Prevention of duplicate-content issues
- Multilingual hreflang only where applicable
- Google Search Console integration readiness
- Bing Webmaster Tools integration readiness

### Structured data

Implement valid, relevant Schema.org JSON-LD where supported by the actual content:

- Organization
- WebSite
- WebPage
- BreadcrumbList
- Service
- Article
- BlogPosting
- Person
- LocalBusiness, only when appropriate
- FAQPage, only for genuine FAQs and without assuming Google rich-result eligibility

Validate structured data against applicable schema specifications and Google-supported feature requirements.

Never add misleading schema markup.

### Performance objectives

Optimize for Core Web Vitals:

- LCP: 2.5 seconds or less
- INP: 200 milliseconds or less
- CLS: 0.1 or less

Treat these as target thresholds at the 75th percentile of real-user measurements.

Aim for Lighthouse scores of 90+ where feasible, while recognizing that laboratory scores vary by environment and cannot be guaranteed.

Make content understandable, discoverable and suitable for accurate attribution in AI-assisted search experiences.

- Google AI Overviews and AI Mode

- Other AI-assisted discovery systems

- Consistent company descriptions

- Original, verifiable business information
- Evidence-backed claims
- Descriptive page titles and headings

- Context-rich service pages
- Authoritative supporting references
- Source and publication metadata

- Updated timestamps when meaningful
- Publicly accessible relevant pages
- Correct canonical and indexing directives

11. Maintain consistent code conventions.

17. Document assumptions and decisions.

After implementing each major module, evaluate:

- Is it functional?
- Is it responsive?
- Is it accessible?
- Is it reusable?
- Is it secure?
- Is it SEO-friendly?
- Does it support the business objective?
- Does it integrate with the real backend?
- Does it follow the established design system?
- Has it been tested?

If any requirement is not satisfied, document the issue and resolve it before considering the module complete.
